# Procedural Volumetric Clouds (Interval Shading)

This project extension enables the generation and rendering of procedural volumetric clouds within the **Interval Shading Tetrahedron** sample. It moves beyond static meshes (like the bunny) to dynamic, mathematically generated volumes representing clouds, storms, and chaotic density fields.

## 1. Overview

We use a hybrid approach:
*   **CPU Generator (`generate_cloud.js`):** Creates a tetrahedral mesh that acts as a "bounding container" for the cloud. It uses 3D Noise (FBM, Domain Warping) to define the shape.
*   **GPU Renderer (`IntervalCompositePS.hlsl`):** Performs ray-marching *inside* the mesh intervals. It calculates lighting, density, and soft edges to create the fluffy, volumetric appearance.

## 2. Generating Clouds

A Node.js tool is provided to generate custom cloud assets (`.vtk` files).

**Script Location:** `Samples/Desktop/D3D12MeshShaders/src/Tools/generate_cloud.js`

### Usage
```powershell
node Samples/Desktop/D3D12MeshShaders/src/Tools/generate_cloud.js [options]
```

### Key Options
| Option | Default | Description |
| :--- | :--- | :--- |
| `--mode` | `grid` | **`soup`**: Disconnected random shards (best for wild/chaotic shapes).<br>**`grid`**: Connected voxel mesh (better for solid/smooth clouds). |
| `--shape` | `cumulus` | **`chaos`**: Triple domain warping (turbulent).<br>**`storm`**: Concave, swiss-cheese holes.<br>**`wispy`**: Sparse, disconnected tails.<br>**`cumulus`**: Classic flat-bottom cloud. |
| `--res` | `32` | Grid resolution (e.g., `64` for high detail). |
| `--thresh` | `0.48` | Density threshold. Lower (`0.2`) = denser/larger cloud. Higher (`0.4`) = sparser/holey. |
| `--out` | `...` | Output path for the `.vtk` file. |

### Example: "The Storm"
To generate a highly detailed, chaotic storm cloud:
```powershell
node Samples/Desktop/D3D12MeshShaders/src/Tools/generate_cloud.js --mode soup --shape chaos --res 64 --thresh 0.2 --out Samples/Desktop/D3D12MeshShaders/src/Assets/IntervalShading/my_storm.vtk
```

## 4. Technical Implementation Details

### The "Soup" vs. "Grid"
*   **Grid Mode:** Generates a connected mesh using Marching Tetrahedra logic. Good for solid objects.
*   **Soup Mode:** Probabilistically spawns disconnected tetrahedra where density is high. This breaks the "convex hull" limitation and allows for floating islands and disconnected wisps.

### Shader Logic (`IntervalCompositePS.hlsl`)
*   **Ray Marching:** We march rays between the `Front` and `Back` depth textures generated by the Mesh Shader.
*   **Depth Fade:** To prevent the cloud from looking like a hard geometric shape (a box or sphere), we force the density to fade to 0.0 as it approaches the mesh boundaries.
*   **Lighting:** Uses Beer-Lambert law for absorption and light scattering.

### Known Limitations
*   **Bounding Box Artifacts:** If the noise generation fills the entire generation grid, the cloud may look "cubical". The generator currently uses radial falloff and domain warping to mitigate this.
*   **Resolution:** extremely fine wisps (hair-like details) are limited by the tetrahedra size and the ray-march step size.
